# Application-Project

## Opis Aplikacji
Jest to aplikacja umożliwiająca zarejestrowanym użytkownikom dodawanie ofert wypożyczenia swoich samochodów. Aplikacja zrobiona w języku php i JavaScript z użyciem lokalnej bazy danych PostgreSQL

## Uruchomienie aplikacji
Aby uruchomić aplikację należy:
  1. Zainstalować Docker
  2. Skopiować repozytorium
  3. Stworzyć container w Docker
  4. Uruchomić aplikacje w przeglądarce: htp://localhost:8080
